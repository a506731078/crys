# crys

> ⚠️ 内容提示（NSFW）：本仓库包含成人/限制级内容相关的流媒体链接清单，请确保在符合法律法规、平台条款与版权授权的前提下使用，并注意未成年人保护。

本仓库当前主要用于存放一组“标题 + 播放地址（URL）”形式的播放列表数据。  
尽管目录名为 `jpg/`，但实际内容并非图片文件。

---

## 目录结构

- `jpg/`
  - `vip.txt`：较小的链接清单（文本格式）
  - `vip1.json`：较大的链接清单（后缀为 `.json`，但内容并非标准 JSON；更像纯文本播放列表）

---

## 文件格式说明

两份文件的核心行结构大致为：

- **分组行**：`分组名称,#genre#`
- **条目行**：`标题,URL`
- **空行**：用于分隔
- **纯数字行**：文件中夹杂了大量仅包含数字的行（疑似原始序号/占位/导出残留），通常不属于“标题,URL”的有效条目

示例（使用占位符，不对应仓库真实内容）：


分类A,#genre# 示例条目1,https://example.com/stream1.m3u8 示例条目2,https://example.com/stream2.m3u8


---

## 内容概览

- `vip.txt`
  - 以分组（`#genre#`）+ 条目（`标题,URL`）形式组织
  - 混合了多类流媒体地址（常见为 `.m3u8` HLS）
- `vip1.json`
  - 结构同样以分组和条目为主，但条目数量更多、分类更细
  - 文件扩展名为 `.json`，但并没有标准 JSON 的对象/数组结构，更适合按“纯文本清单”处理

## 使用与注意事项

1. **合规与版权**
   - 请仅在你拥有合法授权的情况下使用这些链接与内容。
   - 如需公开分享，建议先做版权合规审查，并移除不应公开的资源地址。

2. **安全建议**
   - 不要随意在不可信播放器/网页中打开未知链接，避免隐私泄露与恶意跳转。
   - 建议在隔离环境中做格式解析/清洗（例如仅做文本处理、去除无效行、分类整理）。

3. **维护建议（可选）**
   - 将 `jpg/` 目录重命名为更贴切的名称，例如 `playlist/`、`links/`。
   - 将 `vip1.json` 改名为 `vip1.txt` 或 `vip1.m3u`（若后续转成标准 M3U），避免误导。
   - 增加一个“清洗/转换脚本”（可选）：用于去掉纯数字行、识别 `#genre#` 分组、导出为标准格式。
