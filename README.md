## 文件格式说明

两份文件的核心行结构大致为：

- **分组行**：`分组名称,#genre#`
- **条目行**：`标题,URL`
- **空行**：用于分隔
- **纯数字行**：文件中夹杂了大量仅包含数字的行（疑似原始序号/占位/导出残留），通常不属于“标题,URL”的有效条目

示例（使用占位符，不对应仓库真实内容）：

```

示例条目1,https://example.com/stream1.m3u8
示例条目2,https://example.com/stream2.m3u8
```
